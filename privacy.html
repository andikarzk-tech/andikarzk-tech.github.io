Privacy Policy

Parallel Earth Uploader · Last updated: 25 November 2026

Parallel Earth Uploader is a private automation tool operated by the owner of the YouTube channel Parallel Earth (@whatifparallelearth). It is not offered to the public.

What the tool accesses

With the channel owner's permission (Google OAuth, scope youtube.upload), the tool uploads videos created by the owner to the owner's own YouTube channel and sets their title, description, tags and publish time.

What the tool does not do

It does not collect, store, sell or share personal data of any other person. It does not read viewers' data, comments or analytics. The only credential it keeps is the owner's OAuth refresh token, stored as an encrypted secret in the owner's private GitHub repository.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: contact us through the Parallel Earth YouTube channel.
